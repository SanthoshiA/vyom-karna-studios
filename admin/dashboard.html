Administrators

Administrator access is controlled through Supabase Authentication and the admin_users allow-list.

Loading account...

For security, this browser dashboard does not create or remove administrator accounts. To add an administrator, create/invite the user in Supabase Authentication, then add that user's Auth UID to public.admin_users using the Supabase SQL Editor. To revoke access, remove that UID from the allow-list.

Never share your Supabase secret or service-role key.
